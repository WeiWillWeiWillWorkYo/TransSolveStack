# Commercial Use

Commercial use of TransSolveStack is not granted by the public repository
license route.

Contact Wei CUI for written permission before:

- Integrating TransSolveStack into a commercial product.
- Selling hosted solver-selection or sparse-solver services based on
  TransSolveStack.
- Redistributing modified TransSolveStack code as part of a paid product.
- Using TransSolveStack or contributed selector models in proprietary consulting
  deliverables.
- Packaging TransSolveStack under another brand or implying official status.

Noncommercial research, testing, benchmarking, and contribution use is intended
to be allowed under the PolyForm Noncommercial source-code route and the
project's model contribution terms.
